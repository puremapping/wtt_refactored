# 「交互式视频」概念边界、成型产品与课程作业级可达性

> 调研日期：2026-11-12 ｜ 面向项目：Where to Travel（课程作业 MVP，AI 对话为核心入口，输出个性化行程 / 可解释推荐 / 行程预演）
> 本报告是**产品形态调研**，不是排障，也不是"给老师建议找佐证"。核心任务是把「交互式视频」这个含混词拆开，逐族判断成熟度与可达性，并**明确指出哪些方向对这个项目不现实**。
> 证据强度标注：**强**＝一手官方原文 / 同行评审论文 / 政府采购等可复核文件；**中**＝可信媒体的记者实访或转述官方数字（未经独立复核）；**弱**＝厂商案例页 / 自报数据 / 单一来源 / 搜索摘要。厂商自报数字一律降级，不因数字精确就升格。

## 0. 一句话结论（先给判断）

老师说「交互式视频」时，指向的可能是**四个技术族里完全不同的东西**，它们的成熟度差了十年、成本差了三个数量级。对本项目：

| 方向 | 成熟度 | 对本项目 | 判词 |
|---|---|---|---|
| (a) AI 实时生成可交互视频 / 世界模型 | 研究预览，少数商用 3D 世界生成 | ❌ **不现实** | 拿不到权重和 API，且官方明说无法精确还原真实地点——对"去哪玩"是致命伤[2] |
| (b) 分支叙事互动剧 | 曾成型，**平台方已全线撤退** | ❌ **不现实且方向错** | 生产成本随分支指数增长[14]；它是娱乐叙事，不是辅助决策 |
| (c) 视频内可点击 / 可问答交互层 | ✅ 高度成熟、有免费开源方案 | ✅ **唯一现实可做** | 但要限定形态：不是"做视频"，是给对话产出的行程卡加就地交互[19] |
| (d) AI 数字人 / 虚拟导游实时对话 | ✅ 商用 API 成熟、文旅已有真实部署 | ⚠️ **今天能做，但不划算** | 真实用户反馈显示准确率是硬伤[24][27]；它涨的是 engagement，不是本项目卖的"可解释 + 真实数据"[31][32] |

**不要把四个方向都写成「值得做」。(a)(b) 应当明确放弃，(d) 应当作为"知道存在但不做"的一栏，(c) 是唯一能进课程作业的范围，且必须缩到"交互层"而非"制作视频"。**

## 1. 概念厘清：四个方向各自叫什么

概念混淆有历史原因：爱奇艺 2019 年的《互动视频标准（IVG）》把**分支剧情、视角切换、画面信息探索、X 因子**四种能力打包进同一个"互动视频"名词下[12]，而 SIGCHI 早在 1996 年就专门讨论过"What Does Interactive Mean?"这件事。所以先按**底层机制**而不是按中文译名分。

### (a) AI 实时生成的可交互视频（可玩视频 / 世界模型）

- **学术界名称**：Interactive Generative Video (IGV)、world model / 世界模型、foundation world model、playable video generation、可操控视频生成。
- **权威定义**：arXiv 综述 2504.21853（2025-04-30）把 IGV 定义为"用生成模型产出开放域视频内容 + 通过控制信号与响应反馈实现在线交互"，并把理想系统拆成五个模块：Generation / Control / Memory / Dynamics / Intelligence；列出的三大应用域是**游戏、具身 AI、自动驾驶**[1]。**注意：综述里没有旅游、没有决策辅助。** 这不是为本项目场景长出来的技术。
- **机制**：不用游戏引擎，逐帧自回归生成画面，键盘/鼠标动作作为条件输入；难点是长时一致性（误差累积）和每帧多次/秒的实时计算[2]。
- **状态**：**研究阶段为主，个别 3D 世界生成产品已商业化**（见 §2.1）。不是"没产品"，是"没有能给外部团队按调用付费的稳定产品"。

### (b) 分支叙事互动视频（选择影响剧情）

- **名称**：interactive film / choose-your-own-adventure / branching narrative / 互动剧 / 互动影视；学术上更早的词是 **hypervideo**（非线性视频结构 +  hotspots 等，Hotspots 被定义为"a limited form of hyperlinks"）。[unverified]（hypervideo/hotspot 定义未取到原文存档，属概念性补充）
- **机制**：预拍多条素材，按选择节点跳转，播放器维护状态（Netflix 为此专门做了 state-tracking）；本质是**播放器内的状态机 + 多份预制素材**，与 AI 生成无关[8]。
- **状态**：**曾经高度成型，但 2024–2025 平台方系统性退出**（见 §2.2）。这是本次调研里最硬的"别做"信号。

### (c) 视频内可点击 / 可问答的交互层

- **名称**：interactive video overlay、hotspot video、hypervideo、**shoppable video**（电商向）、in-video quiz（教育向）、clickable video。中文常混叫"互动视频"。[unverified]（术语归名属常识性描述，未取到权威词表）
- **机制**：**源视频不变**，在 HTML5 播放器上按时间轴叠加 DOM 图层——热点、卡片、表单、问答、跳转；H5P 的官方描述就是"仅用浏览器给视频加选择题、填空、弹窗文字、链接、图片、表格，可配置为答对跳到某时间点"[19]。
- **状态**：✅ **完全成熟**，有免费开源（H5P）、个人级 SaaS（Mindstamp $59–299/月）、企业级（Vimeo Interactive / Smartzer）[19][18][21]。与 AI 的关系是**可选**的：热点内容可以由 LLM 生成，但不需要生成视频。

### (d) AI 数字人 / 虚拟导游实时对话

- **名称**：digital human / AI avatar / **Embodied Conversational Agent (ECA)** / embodied AI avatar / virtual tour guide / 虚拟讲解员。[unverified]（术语归名属常识性描述，未取到权威词表）
- **机制**：**严格说这不是"视频"**——是 WebRTC 实时流：STT → LLM(+RAG) → TTS → 口型/表情渲染 → 推流。D-ID 的官方文档把它写成"一个 real-time conversation loop"，渲染只是其中一环（其自报 <200ms 仅指 avatar 模型渲染，不含 STT/LLM/TTS）[37]。
- **状态**：✅ **商用成熟**（HeyGen LiveAvatar、Tavus、D-ID、Synthesia），文旅有真实政府采购部署（见 §2.4、§3）。但它属于"对话式 AI 的一张脸"，与 (a)(b)(c) 不在同一层。

#### 如果老师想的是"AI 交互设计的新形态"

最贴的其实是 **(a)** 或**生成式 UI**（Google 2025-11 的 Generative UI / Gemini dynamic view：模型现场写代码生成定制交互界面来回答这一个 prompt，明确举例"generating a plan for an upcoming trip"[36]）——而 (a) 恰恰是最不可达的那个。若想的是"让行程更可感知"，那是 (c) 的窄义版。这个歧义建议当面确认，不要默默按 (a) 立项。

### 2.1 方向 (a)：世界模型与可玩生成视频

| 产品 | 上线 | 形态与交互细节 | 可核数据 | 证据 |
|---|---|---|---|---|
| **Google DeepMind Genie 2** | 2024-12-04 | 单张提示图生成可键盘鼠标操控的 3D 环境；对象交互、长时记忆（离开视野再回来能正确重绘） | 一致性最长约 **1 分钟**，多数演示 **10–20 秒**；研究型发布，未公开可用[3] | 强（官方博客） |
| **Google DeepMind Genie 3** | 2025-08-05 | 文本 prompt → 实时可导航世界；支持 "promptable world events"（改天气、加角色）；用于 SIMA 智能体训练 | **24 fps / 720p**、一致性"数分钟"、视觉记忆约 1 分钟；**仅向"小批学者与创作者"开放 limited research preview**[2][4] | 强（官方 + The Verge 互证） |
| **Decart Oasis** | 2024-10-31 | 无游戏引擎、逐帧生成的 Minecraft-like 可玩 demo，可下载模型；训练自 Minecraft 游玩录像 | 融资 $21M；TechCrunch 记者实测：**分辨率很低、转身后场景被重排（"忘记"布局）**；demo 跑在 H100 上[5] | 中（记者实测 + 官方融资） |
| **World Labs Marble** | 2025-11-12 正式开放 | 文本/图/视频/粗 3D 布局 → **持久化 3D 世界**，可编辑、扩展、组合，导出 Gaussian splats / mesh / **视频** | 已 GA 对所有人开放；但官方原文把"interactivity"列为**未来方向**："Going forward, a key opportunity is interactivity"[6] | 强（官方博客） |
| （成本参照）**Sora 2 on Azure** | 2025-10-15 | 文本/图/视频 → 视频，非交互 | **$0.10/秒** ＝ $6/分钟（720p）；这是**离线生成**的价格，不是实时交互[7] | 强（微软官方定价） |

**判读**：学术综述自己把 Oasis 和 WHAM 称为"已发布可玩版本、但仍属早期探索"[1]。**唯一 GA 的 Marble 生成的是静态 3D 世界 + 可导出视频，明确把实时交互放在未来时**。也就是说：今天能买到的是"生成一段可看的视频/3D 场景"，买不到"用户能走进去的目的地"。

### 2.2 方向 (b)：分支叙事互动视频

| 产品 | 上线 | 形态与交互细节 | 可核数据 | 证据 |
|---|---|---|---|---|
| **Netflix《黑镜：潘达斯奈基》** | 2018-12-28 | 10 秒限时选择、状态追踪、5 个主结局（含变体）、彩蛋结局；剧本 170 页 | **拍摄 5 小时素材**支撑 90 分钟主线体验（单次可达 2.5 小时）；筹备制作约 18 个月；Netflix 产品创新总监称 **94% 观众主动做选择**；**从未公布总观看人数**[8] | 中-强（THR 引 Netflix 高管原话 + Variety 复核素材量[10]） |
| **爱奇艺《他的微笑》+ IVG/IVP** | 标准 2019-05-09；剧 2019-06-20；Premiere 插件 2019-07-23 | 首个"带入式互动影视"；**21 个选择节点、17 种结局**；IVP 插件直接嵌 Adobe Premiere，边剪边加分支、可预览[11][12][13] | 平台级标准与工具链完整，但**未查到公开的观看/完播数据** | 强（平台官方公告，效果数据缺失） |
| **B 站互动视频（UGC）** | 2019-07 内测 / 08-15 公测 | Web 端编辑器搭剧情树；1 万粉以上 UP 主先行；100 万元创作奖金[15] | 头部作品《操控广场大妈拯救 B 站》11 小时 51.9 万点击；但同期报道指出**互动视频播放量与 UP 主日常视频持平甚至更低，而成本增 50%+**[14] | 中（媒体 + 平台公告） |

**决定性事实——平台方全线撤退**：
- Netflix 于 **2024-12-01 下架 24 个互动特辑中的 20 个**，发言人称"技术达到了目的，但现在随着我们专注其他领域的技术努力，它受到了限制"，并转向游戏 / GenAI for Games[9]；**2025-05-12 连最后两部（含 Bandersnatch）也全部移除**[10]。
- 分支视频编辑器的标杆 **Eko Studio 于 2024-11-19 关闭编辑器**，只提前一周通知，且**项目无法整体导出**——用户只能逐段下载转码后的片段 + 截图剧情树[20]。Eko 曾融资超 $20M、与沃尔玛签 $250M 合作，仍转型去做 AI 商品视频[20]。
- 更早的整合：Rapt Media→Kaltura(2018)、HapYak→Brightcove(2021)、Wirewax→Vimeo(2021，后变成企业级 Vimeo Interactive)[21][22]。
- B 站侧有单一来源称 2023 年起限流、互动视频栏目从 App 端消失（**弱证据，未独立复核**，且与 2025-12 B 站客服仍在发互动视频答疑相冲突，此处不下定论）。

→ 行业复盘给出的结论不是"互动视频失败"，而是**锁死在单一专有平台里的互动视频失败**；活下来的是营销热点层、教育测验层、分支叙事工具层[21]。

## 3. 文旅域真实部署与"非宣传稿"的用户反馈

### 3.1 确实有真实部署（不是 PPT）

- **滕王阁 AI 导游「王勃」**：2023 五一首上"智能背序亭"，2024 升级为扫码即用的 AI 导游系统——大语言模型实时问答 + **30 个自动感应讲解点 + 66 个拍照识别点 + 26 个文化小故事 + 藏头诗**；官方转述累计 **107,701 名游客登录、讲解点自动触发 674,449 次、拍照识别 22,955 次、手动触发 154,190 次**[23]。（**中**：新华网/南昌日报转述系统负责人，数字无第三方审计；且"触发次数"≠"满意"。）
- **首都博物馆「京慧」、杜甫草堂「AI 杜甫」、伪满皇宫「五号讲解员」、国博「艾雯雯」**：中国旅游报记者实地走访，馆方称"京慧"经过半年多知识库训练、高峰时游客排队与她对话；合作方自评"五号讲解员"**约达初中文化水平**[42]。（**中**：记者实访，但引述多为馆方/供应商口径。）
- **广州东山柏园「大模型+数字人」**：百度文心 + **柏园专属 RAG 知识库**（历史文献/考古成果/建筑档案），微信小程序承载，支持每人每日 300 次个性化咨询，官方称**游客平均停留时间 +40%**[43]。（**中**：省文物考古研究院主导项目，羊城晚报转述；"+40%"无测量方法说明。）

### 3.2 真实用户反馈（这是本报告最该看的一节）

**上海浦东美术馆 × 豆包 AI 讲解员（2026-01 上岗，记者 4 个月后回访）**——目前找到的最扎实的第三方实访[24]（**强**：上观新闻记者现场采访普通观众 + 资深讲解员 + 馆方，正反两面都写）：

- 好评侧：能讲地毯符号寓意、识别莫卧儿匕首的昆丹镶嵌工艺、用上海话回应；讲解员承认"AI 很会拍马屁"、也确有一个自己不知道的知识点值 100 分。
- **吐槽集中在交互方式而非技术**：「打开视频通话，你就得不停地说，豆包没有加速功能，一讲起来就很啰嗦，我还必须戴耳机」；「很多人不戴耳机就外放……很多瞬间我以为自己在菜市场」。
- **准确率是硬伤**：「豆包没有准确识别出我拍的展品，**超过一半识别错误或根本没识别出来**，还不如老老实实扫二维码看作品」；「豆包没识别出来就开始胡编，一看根本不是我问的那幅画——碰到两次都是这样」，这叫**答非所问 / 幻觉**。
- 资深讲解员贾布花了 5 小时深度体验，把 AI 回答分成"正确 / 错误 / **无法判断真伪却言之凿凿**"三类，并当场勘误：把《和平鸽》误认成公鸡、把摄影师说成毕加索女婿、把《玛雅与洋娃娃》张冠李戴成帕洛玛。她的判词对本项目尤其重要：**"如果是'小白'观众，就算说错了也识别不了……但凡我的追问超过三步，可能就超出了我的知识储备，不知它是对是错，这其实很危险。"**
- 结论是"不是对手是队友"；**AI 导览免费，但人工讲解 100 元/60 分钟依旧场场约满**，讲解员数量未减[24]。
- **这些正面案例共同的结构是：AI 做"标准化即时问答"，人保留"串联作品、回应情绪、调整节奏"**——本项目若在报告里引用这些案例，应引这个结构结论，而不是引它们的上线喜报。

**界面新闻 2024 国庆用户访谈**（**中**：媒体访谈 4 位真实用户，化名，个案不可外推但问题类型清晰）[25]：
- 「用 AI 当导游，连定位都不准确」：30 元/人的景区 AI 导游小程序，**两个建筑离得近就定位错乱、位置稍变就反复错乱讲解**；「对'AI 导游'提的问题不能太复杂，否则得到的答案只能是'很抱歉，这个问题我无法回答'」。
- **内容陈旧**：AI 推荐的小店「已经关门半个月了」；老龙头门票 AI 报约 100 元、实际 60 元；想找"真正小众"的地方，问十遍仍是网红打卡地——因为训练数据本就来自网络。

**第三方测评（最权威的一条量化证据）**：北京第二外国语学院数字文旅研究中心《AI 文旅讲解类应用测评报告（第一期）》测评 **12 款主流 AI 语音讲解产品**（通用大模型 / 平台型 AI 助手 / 馆方智能体），4 个一级维度 17 项二级指标，结论是**12 款综合总分全部未达 60 分，讲解题与简答题 0 分率高达 71.8%**；整体"可用但不成熟"，**内容准确性是最大短板、幻觉风险突出**；通用大模型易幻觉、平台型助手拒答率高、馆方智能体知识覆盖有限[27]。（**中-强**：正式研究机构测评，但我读到的是报告摘要/发行页，未逐页核原始 72 页 PDF，故不标满。）

**系统性的行业批评**：《浙江日报》"莫让数智文旅变成'数字盆景'"直指「少数花重金打造的数字平台，**日均活跃用户却寥寥无几**；按高标准配置的互动装置，**没过多久便无人维护**」「屏幕越装越多，运维成本越来越高，却没带来游客体验和当地商户收入的提升」「我们去旅行，是为了看真实的风景，不是看屏幕里的风景」[26]。（**强**：党报评论员署名，属观点但有具体观察。）这与玉龙雪山采购里"三年免费运维 + 第四年 10%"的条款互为印证：**维护成本是结构性的，不是意外**。

**成本/加载侧的从业者复盘**（**中**，从业者自述，方法论可借、数字不可当基准）[30]：AR/数字互动内容制作成本约为静态物料的 **3–5 倍**；景区人流密集时基站拥塞、加载失败率明显上升；「游客对数字互动的耐心极短：**扫码超过三秒没反应，就会直接放弃并留下负面印象**」；内容一个月不更新体验就衰减，识别点换了海报/挪了展板/光线变了识别率就掉。

**合规与商业风险**（**强**）：解放日报/上观调查发现，抖音、视频号对"非真人直播的代播内容"有明确限制或禁止，商家花 2–6.5 万元采购数字人服务后被反复封禁、法院判解除合同退款；行业里 114.4 万家"数字人相关企业"多为贴牌代理，"演示用原厂模型、交付粗制滥造模型"；浙江省已出台指引专门规范 AI 数字人直播[28]。硅基智能招股书也自承"人工智能技术的缺陷或不足可能会降低我们解决方案的有效"、前五大客户贡献 87.5% 营收[44]。

> 本项目自己的 `wtt_miniapp/RESEARCH-20261112.md` 已列过拟人化陪伴型导览的算法备案 / 安全评估 / 显著位置公示等门槛——本调研的用户反馈证据说明，**比合规更早卡住项目的是准确率与交互方式**。

### 3.3 学术界怎么说"数字人到底有没有用"（反直觉，很重要）

| 研究 | 设计 | 结果 | 强度 |
|---|---|---|---|
| Zhang et al., *IJHCI* 2025-05（XJTLU）[31] | 虚拟博物馆中对比 文字标签 / chatbot / **avatar 导游** | avatar 组的**参与度与整体体验显著更高**；但**三种方式的学习成果无显著差异** | 强（同行评审） |
| Pakinee et al., *Informatics* 2026 13(3):42[32] | N=75 控制实验，VR 博物馆：纯语音 / 语音+文字 / 语音+具身 avatar，内容恒定 | **语音+文字的"感知信息质量"最高**（PIQ F=54.68, p<0.001）；**avatar 组"用户参与度"最高**（UES p=0.003/0.004）；认知负荷三者无显著差异 | 强（同行评审，含统计表） |

**这两篇合起来是本报告最关键的一条判断依据**：数字人/具身 avatar **买来的是 engagement，不是信息质量，也不是决策质量**。而本项目 README 的差异化写的是"动机驱动 + 真实数据交叉 + 可解释性 + 置信度 + 推荐理由"——**把一个提升参与度但降低感知信息质量的界面放到核心决策入口上，是与项目定位相冲的**。同时，"恐怖谷"在学术侧并不是最硬的负面结论（更多是行业评论；观察者网那篇"已跨过恐怖谷"是京东云言犀负责人在行业大会上的厂商表态，**弱**），真正被实测反复打中 hallu的是**事实准确性与交互姿态**。

## 5. 与「对话」的结合方式：替代对话，还是对话的产物？

### 5.1 有没有产品"用交互式视频替代对话"

**基本没有成功案例。** (b) 的 Netflix / 爱奇艺给的是"选项按钮"而非自然语言对话，且已全线撤退[9][10]；(a) 的世界模型给的是键盘鼠标导航，官方用途是训练智能体[2]；(d) 的数字人**本身就是对话**，视频只是它的脸，不构成"替代"。把核心决策入口从对话换成视频选择，等于把本项目已确认的优势（动机挖掘、可解释、多行追问）换成一个已被平台方放弃的形态。

### 5.2 有没有产品"把视频当作对话的产物"

**有，而且这条线正在成型**——这是最值得借的形态：

| 产品 | 做法 | 证据 |
|---|---|---|
| **Idomoo Lucas ChatGPT Plugin**（2023） | 对话里说要什么 → ChatGPT 写脚本 → 调视频平台 → 一次返回 4 个视频版本；官方用例直接写"帮你规划下次度假的视频"[33] | 中 |
| **HeyGen ChatGPT App**（2026） | **"Your videos start where your prompts end"**：对话内生成视频，并**在对话里继续迭代**（改脚本、换视觉、调语气），不离开 ChatGPT[34] | 弱（厂商页）+ 形态可核 |
| **OpenAI Apps in ChatGPT / Apps SDK**（2025-10/11） | 把第三方能力以"可与之对话的 App"嵌进对话，输出富交互卡片而非纯文本[36] | 强（官方） |
| **Google Generative UI / Gemini dynamic view**（2025-11-18） | 模型**现场写代码生成定制交互界面**回答这一个 prompt；官方原文明确把"generating a plan for an upcoming trip"列为差异化场景之一；评测注明"**当忽略生成速度时**"生成式 UI 被人类评审显著偏好[36] | 强（Google Research）；注意其自承的速度前提 |
| **Mindtrip**（2024-05 正式发布） | 对话 → 不止聊天回复，而是**完整行程 + 日历 + 可编辑可分享 + 图片 + 地图**；约 600 万 POI / 30 国；$7M 种子轮、对游客免费[35] | 中-强（PhocusWire 专访 CEO） |
| **Layla / Wanderboat**（本项目既有竞品调研已覆盖） | Layla 用**视频 swipe 在"还没决定去哪"时激发灵感**再进对话；Wanderboat 用**带视频的景点卡片流 + Ask AI**（详见 `docs/research/ai-travel-competitive-landscape.md`） | 项目内部文档 |

**结论**：成型产品的共同结构是 **「对话是入口与控制器，视觉产物是对话的输出」**，不是反过来。视频/交互层**不替代对话，也不与对话并列**，而是挂在对话结果上的一层可操作视图。这也和本项目 `docs/research/waiting-and-process-visibility.md` 的既有发现一致（结构化/可交互的中间结果优于纯文本 CoT；边生成边把站点卡片"落"到右栏强于"正在生成行程…"），以及 `ai-travel-competitive-landscape.md` 的判断（"对话 + 行程卡（可编辑）"是当前体验天花板；"可晒的视觉产物"是留存引擎之一）。

需要明确的是，这五家里**只有 Mindtrip / Layla / Wanderboat 真正把"行程"作为主产物**，且它们的视觉形态是卡片、地图与图片，不是视频。Idomoo 与 HeyGen 只是"把对话内容渲染成视频"的通用工具，OpenAI Apps SDK 与 Google 生成式 UI 是通用交互容器。也就是说，**"对话 → 可交互视觉行程"目前没有可直接照抄的成型范式**，能借的是结构（视觉挂在对话结果上），不是某个产品的现成做法。

### 5.3 对本项目的具体接法（若一定要回应老师那句话）

不要做"一段可交互的视频"，做**「行程作为可交互的时间轴/卡片视图」**——它落在方向 (c) 的窄义上，且能复用现有 `/api/chat` 与右栏渲染：

1. 对话产出结构化行程（已有）→ 右栏渲染时间轴/地图/卡片（已有架构）。
2. 在卡片上叠 (c) 的能力：**热点**（点景点名就地展开来源与置信度）、**就地问答**（选中某站直接追问"为什么安排在这里"，复用对话接口并带上下文）、**分支**（点"换成室内/少走路"直接触发一次重排，等价于分支叙事但零素材成本，因为分支的是**数据**不是**视频**）。
3. 视频只作为**可选静态素材**：已有的景区图片/官方宣传片缩略图，或最多用 H5P 给一段预制短片加热点；**不做实时生成、不做数字人**。
4. 若要"可晒"，按竞品调研的结论输出**可分享的视觉产物**（手绘风行程图 / 卡片长图），比生成视频便宜三个数量级且更符合国内传播习惯。

> 这个接法还有一个额外好处：分支的是**结构化行程数据**，所以分支成本是 O(1) 的重排，而不是 (b) 的"每加一个结局多拍一段素材"。它绕开了 §2.2 里让平台方撤退的那条成本曲线。

## 6. 已知的坑（按证据强度排序）

| 坑 | 具体证据 | 强度 |
|---|---|---|

## 7. 明确不做什么（给决策的一页）

1. **方向 (a) 世界模型/可玩生成视频：放弃。** 三个独立理由：① Genie 3 仅邀请制研究预览、无公开 API/权重[2][4]；② 官方把"无法精确模拟真实地点"列为 limitation[2]——旅游决策要求地点真实可核，这一条直接判死；③ 学术综述把 IGV 应用域定在游戏/具身/自动驾驶[1]，没有决策辅助场景。可以在报告里引用它证明"看过前沿"，但**不写进 MVP，也不写成'值得探索的下一步'**。
2. **方向 (b) 分支叙事互动剧：放弃。** 成本随分支指数增长（2 结局 +70%，5 小时素材/18 个月）[14][8]；平台方 2024-12 下架 20/24、2025-05 全部清零、Netflix 发言人称该技术"现在受限"[9][10]；Eko 关停且项目不可导出[20]。而且它是**叙事娱乐**，与"辅助用户做去哪的决策"不同构。
3. **方向 (d) 实时数字人：不做 Demo，只做"已调研"记录。** 商用 API 一天能接上，但：① 真实景区交付是 307.65 万 / 40 项 / 120 天 / 3 年运维量级[29]；② 12 款产品测评 0 分率 71.8%[27]、浦东美术馆实访"超一半识别错误"[24]；③ 学术证据显示它涨参与不涨信息质量[31][32]，与本项目"可解释 + 真实数据交叉"的卖点相冲；④ 合规与平台封禁风险[28]。**如果一定要展示"我们考虑过数字人"，正确写法是列为本项目的排除项并给出上述三条理由。**
4. **方向 (c) 做，但收缩到"交互层"：** 不做视频拍摄、不做实时生成、不做数字人；只在对话产出的行程卡/时间轴上加热点、就地问答、数据分支。零生成成本、纯前端、可复用现有后端，H5P 或手写 HTML5 均可[19][18]。
5. **不要引用 §6⑩ 的任何百分比作为"有效性证明"**——报告里凡出现这些数字，必须紧跟"厂商自报，未经独立复核"。

## 8. 查过但证据不足 / 未解决

- **B 站互动视频 2023 起限流、栏目从 App 消失**：仅单一行业站说法，且与 2025-12 B 站客服仍在发布互动视频答疑相冲突，**未采信、未写入结论**。
- **Netflix / 爱奇艺互动内容的完播率、留存、会员拉动**：Netflix 明确"从未公布总观看人数"[8]，爱奇艺未查到公开效果数据；故 §2.2 只有形态与素材量，没有效果数据。**不能用"94% 主动选择"论证商业成功**——那是产品创新总监自述的内部指标，且 7 年后作品被下架。
- **北二外测评报告 72 页全文**：本次读到的是发行/摘要页，数字（12 款 / 71.8% / 17 指标）来自该页，未逐页核原始 PDF，故标"中-强"而非"强"。
- **实时 avatar 全链路延迟**：只取到厂商间互相 benchmark（1.2–1.4s 中位数）与开发者论坛 >10s 初始化黑屏报告，均为**弱**证据；无独立第三方复现实测。本报告因此只给量级，不给精确值。
- **恐怖谷在文旅场景的独立实证**：检索到多篇相关期刊论文（IJCHM 2025、meta-human 接受度 280 样本等）但未取全文结论，故 §6⑧ 标弱，不作为主要风险。
- **"交互式视频"这个词在老师语境中的确切所指**：无法从材料判定，需当面确认（见 §1 末尾）。本报告按四族并列处理，不替老师选定。
