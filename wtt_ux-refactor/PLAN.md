### P2 有效推荐  🚧 进行中

**为什么**：信任数据显示 55% 用户遇过错误推荐、16% 被推荐过不存在的地方；推荐不准，体验再好用户也不会回来。

**优先级澄清（阿哲 2026-10-29）**：有效推荐与优化使用体验是**两条都要抓的线，并行推进**；「优先」只表示**两者遇到冲突时，以有效推荐裁决**，不是串行顺序、不是先做完一条再做另一条。

- [x] 跨画像 Top-5 Jaccard 重合度诊断 —— 假设被推翻，见下方「诊断结论」

- [ ] 高德在线评分做阈值否决（协议 3.5 禁存储，只在线读）
- [ ] 行程可行性改为带时间窗模型（TOPTW 而非 TSP）

#### 诊断结论（2026-10-29 实测，非推测）

**原假设**：40% 权重压在景区等级上 → 不同动机的推荐结果几乎一样。
**实测结果**：**假设被推翻**。7 动机两两 Jaccard 大部分为 0.0，推荐对动机高度敏感（首个推荐去重 5 个、全部选中去重 19/35）。

但诊断暴露了三个更实际的问题：

1. **分数压缩到 0.005 级**：「成就/完成」top5 分数 [0.490, 0.490, 0.489, 0.485, 0.485]，全池区间仅 0.063~0.58。排序实际由「等级是否相同」这种二元信号决定 —— 精细打分是假象。对应调研里「全是平庸选项 Precision 也是 1.000」。
2. **排除项一刀切误伤**：「恢复/逃离」下故宫得分 0.099、reasons 为空。因为 `INDOOR_HINTS` 含「博物」，故宫被判为室内博物馆扣光，而故宫其实是露天的。想逃离加班的用户一个故宫都看不到，拿到的是黄芩仙谷、爨柏景区这类冷门地方。
3. **规则表本身不完整**：「美食/感官」与「文化/沉浸」Jaccard = 1.0（完全相同）。因为「美食/感官」规则里没有任何美食信号，复用了 `prefer_culture_hint`。

**共同根因**：等级当主分（5A 其实只是便利性认证）、场所类型靠名称猜（粗粒度易误判）。

**验收判据（诊断）**
```
7 动机 Top-5 Jaccard 矩阵已产出；故宫在「恢复/逃离」下得分 0.099 可复现
```
